# Quran FM — نسخة الموقع الثابت

بدون قاعدة بيانات، بدون خادم تطبيقات، بدون حسابات أو مفاتيح API. HTML/CSS/JS. لا يحتاج npm أو عملية بناء.

## التشغيل
- فك الضغط. لتجربة كاملة على Windows شغّل START-WINDOWS.bat (يتطلب Python 3). أو `python -m http.server 8080 --bind 127.0.0.1` ثم افتح http://localhost:8080.
- ارفع الملفات الموجودة في المجلد إلى مستودع GitHub، اربطه بمضيف صفحات ثابتة. في Vercel اختر Other، دون Build Command، والمخرج جذر المشروع. أضف الدومين المطلوب من إعدادات الاستضافة. لا تستخدم خطة غير تجارية لموقع تجاري.
- عدّل بيانات التواصل في index.html وprivacy.html وterms.html إذا لزم. أضف sitemap وcanonical بعد تثبيت عنوان الموقع النهائي. لا توجد إعلانات حالياً ولا وعد بقبول AdSense.

## الوظائف
- فهرس MP3Quran العام للقراء والروايات والسور والإذاعات؛ احتياطي بستة قراء عند تعذر تحميل الفهرس. يحتاج الصوت نفسه اتصالاً بالإنترنت. المحطات الحية من المصدر؛ قوائم الموقع شخصية غير متزامنة.
- 114 سورة، تشغيل المصحف الكامل، قائمة انتظار قابلة للترتيب، تكرار، مفضلة وقوائم محفوظة، حفظ موضع التلاوة، إعادة محاولة الاتصال. بدء الصوت يتطلب نقرة من المستخدم وفق سياسات المتصفحات.
- نص عثماني من Al Quran Cloud وترجمة إنجليزية أو التفسير الميسر عند الطلب، موضع قراءة محفوظ. عداد أذكار بعد الصلاة. واجهة عربية وخيار إنجليزي للأجزاء الرئيسية؛ أسماء القراء والسور والأذكار وبعض النصوص تبقى عربية. لا يوجد تزامن آية بصوت ولا مواقيت صلاة في هذه النسخة.
- PWA مع حفظ واجهة الموقع للعمل دون اتصال، لا تحفظ ملفات الصوت أو النصوص الخارجية تلقائياً.
