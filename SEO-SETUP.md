# QuranFM SEO and monetization

- Search Console: use domain property 5starth.com if verified, or URL prefix https://quranfm.5starth.com/ and verify with Google's real token. Submit https://quranfm.5starth.com/sitemap.xml. Sitemap is not a guarantee of indexing.
- AdSense: root 5starth.com is the review site. Subdomain ads.txt and publisher verification meta on homepage are ready. No ad-serving scripts added. Before monetization: wait for Ready, review recording/image rights, avoid ads inside Quran reader/audio controls and thin pages, configure certified CMP where applicable. No religious-personalization targeting.
- Vercel Analytics: enable Web Analytics in project dashboard and redeploy if needed; optional consent on website. No invented visitor counts. 
- Sources: https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap ; https://support.google.com/adsense/answer/81904 ; https://vercel.com/docs/analytics/quickstart
